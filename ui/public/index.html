How It Works

L1Machine Learning

Runs entirely off-chain. Features engineered from behavioural data, model inference produces integer score 0-1000. Raw data never leaves this layer.

L2Hyperledger Fabric

Stores only Poseidon commitments of scores plus loan event metadata. No PII, no raw features. Regulatory observer has read-only access.

L3ZK-SNARK (Groth16)

Proves threshold eligibility without revealing the score. Lender verifies the proof locally and learns only "score >= threshold".
